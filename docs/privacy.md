# 数据与隐私说明（cista v1）

本文描述服务端实际保存什么、能读什么、删除与备份的边界，以及所有者需要自己保管的东西。
它是产品行为说明，与部署环境无关。

## 1. 服务端能读什么

| 内容 | 服务端是否可读 | 落盘形态 |
|---|---|---|
| 私有笔记（标题 + 正文） | **不可读**（端到端加密，密钥只在客户端） | `private.db` 里只有信封：`wrap`（MK 包裹的 CK）与 `body`（CK 加密的正文） |
| 私有附件（客户端加密后的二进制） | **不可读**（上传前已加密） | 内容寻址文件 + `blobs(scope='private')` 元数据 |
| 共享链接的标题、文件名、大小、MIME | 可读 | `shared.db` + 共享 blob |
| 共享文件内容 | 可读（设计如此） | 分块 XChaCha20-Poly1305 静态加密；密钥在服务端配置 |
| 设备公钥、设备名、创建/吊销时间 | 可读 | `devices` 表 |
| 分享 token | 只存 SHA-256 | `share_links.token_hash` |
| 口令（可选） | 只存 Argon2id 哈希 | `share_links.passphrase_hash` |
| 日志 | 不含正文/标题/文件名/token/口令/密钥 | 结构化 JSON，令牌只写指纹 |

## 2. 服务端不保存什么

- MK（私有主密钥）、CK/FK、设备私钥：只在客户端内存或平台安全存储。
- 分享 token 明文：创建后只在响应里返回一次，服务端只留哈希；日志与 URL 均不出现。
- 私有笔记的明文、私有附件的明文。

## 2.1 客户端本地都存了什么

| 数据 | 位置 | 是否秘密 | 说明 |
|---|---|---|---|
| 服务器地址 | `localStorage:cista.server.base` | 否 | 用户首次启动填写；清空即回到「同源」 |
| 设备 id | `localStorage:cista.device.id` | 否 | 只用于找回钥匙串里的种子 |
| 设备私钥种子 | 系统钥匙串 / Android Keystore | 是 | 桌面 Secret Service / Credential Manager；Android 优先 Keystore |
| MK | 内存（桌面可选系统安全存储） | 是 | 刷新/退出即锁定，除非用户显式记住 |
| 搜索索引 | 内存 | — | Web/桌面都不落盘（`design.md` §2.5） |

服务端不接收服务器地址字段，也不据此做任何识别。

## 3. 删除与生命周期

| 动作 | 结果 |
|---|---|
| 删除笔记 | 笔记行标记删除，增量同步不再返回；共享工作区里由该笔记投影出的文件按级联规则处理 |
| 归档工作区 | 新建私有笔记承载内容，原工作区进入过渡区（计配额、不自动删除） |
| 归档完成 / purge | 释放共享 blob 引用；引用归零时删除本体与元数据 |
| 撤销分享链接 | 立即失效；单文件链接的共享副本引用减一，归零即删 |
| 撤销设备 | 该设备的签名请求立即 401；已存在的分享链接不受影响（可单独撤销） |
| `cista-server gc` | 回收过期/用尽的链接与过期票据；释放无人引用的共享副本 |

已知边界：

- **私有附件没有自动回收**：内容寻址、按哈希去重，删除笔记不会自动删除附件（服务端无法解析密文引用关系）。
  需要彻底清理时，由所有者清空私有附件目录并重建索引（属于运维操作，会丢失未重新上传的附件）。
- **共享内容的静态加密密钥轮换**需要重新写入数据（v1 不提供在线重加密）。

## 4. 备份

- 备份包含：两份 SQLite 快照 + blob 清单 + blob 本体；仓库由 restic 加密，保留 7 daily / 4 weekly / 6 monthly。
- 备份中私有内容仍是密文；共享内容在备份里同样是静态加密后的形态（连同服务端密钥一起恢复才能读）。
- 删除数据不会追溯删除已有备份；备份保留期内数据仍可恢复——这是有意的（防误删），所有者需知悉。

## 5. 所有者自己必须保管的东西

1. **MK 恢复码**：丢失则所有私有笔记永久不可解（服务端无法代为恢复）。
2. **共享静态加密密钥**（`CISTA_STATIC_KEY`）与**备份仓库密码**：与 MK 分开存放。
3. 备份可恢复性的定期演练（见 `scripts/restore-drill.sh` 与 `docs/specs/restore-drill-log.md`）。

## 6. 对外分享的边界

- 分享意味着**服务端与持有链接的人**都能读取该内容；不要用分享链接承载只应端到端加密的材料。
- 链接可设置口令、过期时间与次数上限；访问日志只记录指纹，不记录 token。
- 未设置外部告警与通过安全评审前，不应对公网开放分享。
