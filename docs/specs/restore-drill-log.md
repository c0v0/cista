# 恢复演练记录

每次演练追加一行：`scripts/restore-drill.sh <空目录>` 会输出可直接粘贴的 Markdown 行。
**人工部分**（必须补在“备注”列或下方）：用 MK 解开一条私有笔记、打开一次分享链接并上传/下载。

| 时间（UTC） | 快照 | 自动耗时 | 备注（人工结论） |
|---|---|---|---|
| 2026-10-24T00:00Z | 示例（首次演练前删除本行） | 12s | 示例：MK 解笔记 ✓ / 分享上传下载 ✓ |

## 演练步骤（与脚本对应）

1. 全新目录；`restic restore latest`（或本地快照）恢复 `private.db`、`shared.db`、`blobs/`。
2. `PRAGMA integrity_check` 两份库均为 `ok`。
3. blob 清单对账：清单里每个 hash 存在且大小一致。
4. 用恢复出的数据启动服务，`/healthz` 200。
5. 人工：客户端用 MK 解密一条笔记；创建分享链接、上传、下载、编辑 Yjs。
6. 记录耗时与结论；失败则按 P11 复盘并写清门禁缺口。

## 失败模式（看到即停）

- 用 `cp` 复制活库、备份与源同盘、密钥与备份同处、共享明文未加密、从不演练。
