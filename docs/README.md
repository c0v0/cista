## 客户端如何连接服务器

所有客户端（Web、Linux/Windows 桌面、Android）共用同一套 React SPA：

1. 首次启动进入「连接服务器」页，填写 `https://<你的域名>`（可带路径前缀）；
2. 点「测试连接」会请求 `<地址>/healthz`，返回 `ok` 才算通过；
3. 地址保存在本机 `localStorage` 的 `cista.server.base`（非秘密），
   桌面/Android 还会把设备种子存进系统钥匙串；
4. 之后可在页脚「更改」或配对页「更换服务器」修改；换服务器会锁定当前会话。

Web 同源部署（同一个域名同时提供 SPA 与 API）可以直接选「使用当前站点」。
构建期也可以用 `VITE_API_BASE` 烧入默认地址，用户仍可在设置页覆盖。
